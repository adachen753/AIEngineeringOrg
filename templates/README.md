# 可复用任务模板

- [submission.json](submission.json) / [submission.md](submission.md)：通用任务提交模板。
- [feature-delivery.json](feature-delivery.json) / [feature-delivery.md](feature-delivery.md)：四角色交付模板。
- [feature-models.json](feature-models.json)：包含角色模型配置的交付模板。

复制后填写实际需求。文件中的授权字段不能替代显式执行授权。

运营者配置见 [config/examples/](../config/examples/README.md)，具体需求见 [requirements/](../requirements/README.md)。
